# T1：继续做输入精度审计

2026-11-16 · Theodore → Fable · 当日可行性结果

**判定：继续。** 对 FinQA 的 1,147 道公开测试题，196 题有一致输入的越界见证，占全部题目 **17.09%**，超过原定 5% 门槛。该比例的含义是：**在已绑定输入、半末位舍入及独立输入盒的假设下，gold program 的输出可以跨出 1% 容差**。它不直接表示标注错误或整份财报无法确定答案。

| 测量 | 结果 |
|---|---:|
| 通过严格解析和来源规则的 test 题目 | 731 / 1,147 |
| 1% 容差外有具体可行输入见证 | **196 / 1,147 = 17.09%** |
| 按 gold 显示位数的格子越界 | 375 / 1,147 = 32.69% |
| 增长率组，1% 规则 | **90 / 230 = 39.13%** |
| 全部公开 train/dev/test，1% 规则 | 1,469 / 8,281 = 17.74% |

test 中 416 题排除、另 3 题区间判定未解决；不能把它们算成稳定。所有主计数都要求具体越界输入，未把宽松区间外包络当作反例。1% 与显示位数是任务指定审计口径；FinQA 官方实际是最终保留五位小数后比较执行答案。

**一个例子。** BlackRock 的租金与设备费用显示为 137 和 133 百万美元，程序增长率约 3.0075%。两个真实量若为 136.5005 和 133.4995，仍分别显示为 137、133，但增长率变为 2.24795%，远超 1% 相对容差。两次引用基数使用同一个变量。[逐题证据与代码](results/per_question.jsonl)

**重复精度。** 完整扫描 test 的 380 页产生 54 个候选位置对，经逐项源文核对确认 35 对、否定 16 对、待定 3 对。23 道题完成不同披露位置的单来源替换，4 道跨 1%、13 道跨显示格。另有“两个年份都写 2.6、精表实际为 2.616 和 2.572”的双角色例单列。这是所检索模式的确认下界，尚非全部语义重复的普查。

**数学结果。** 对增长率 (g=b/a-1)，输入半宽为 (h_a,h_b)，一阶半径为 ((|a|h_b+|b|h_a)/a^2)。完整舍入单位相同为 (u) 时，原任务公式需要 (u/2) 因子。在 1,307 道严格增长率子集里，将半宽模拟缩小 1、10、100、1000 倍，精确越界数为 **529、143、7、0**；一阶阈值预测本样本无错例，但一阶式本身不是严格界。单纯改写单位不会增加信息。

**新颖性与下一步。** 定向查重未发现完整同题；XBRL 已有舍入区间、区间运算和重复披露取交集规范，不能把这些当新理论。值得继续的是基准发生比例与非线性敏感性。下一轮应把确认的重复披露及会计约束合入可行域，并以真实更精细披露检验改善；若收紧后信号消失，就停止“全文不可确定”的主张。
