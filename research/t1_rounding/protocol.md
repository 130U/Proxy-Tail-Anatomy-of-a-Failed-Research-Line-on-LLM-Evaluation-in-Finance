# T1 首次统计前的口径

日期：2026-11-16（America/New_York）。入口为 `tasks/T1_rounding.md`；本目录独立于此前绝对评分实验。

## 查重与研究对象

首轮定向检索及近邻全文核验未发现完整重复，细节见 `literature.md`。这不等于穷尽文献，也不宣称已用满半天的查重预算。区间算术、舍入误差传播、XBRL 重复事实区间交集均属已有方法。本研究只测量公开问答数据在明确舍入模型下的敏感性。

研究量是**给定 gold program、已绑定的报告数字及独立舍入盒之后，答案能否保持在预设判分区间内**。它不等于基准标注错误，不等于模型错误，也不自动证明整份原财报没有足够信息。若问题本来要求按显示数字计算，基准任务本身仍可确定。

## 数据、统计分母与执行

- 主结果：官方 FinQA 公开 test 全部题目；dev、train 分开报告，另列三者合计。不训练、不调用付费 API、不依结果挑题。
- 精度取自 `table_ori` 与基准提供的文本数值字符串，不能取自程序浮点数或 `exe_ans`。保留末尾零。先使用 gold 支持事实定位，再利用源表格/文本；没有可靠绑定的题目单列。多层表头以行标签对齐，不能按物理行号直接索引。
- 每个可纳入报告数值取显示末位的半单位为半宽。数据检查发现 `const_*` 词汇也会编码实际报告数值，故来源支持中出现匹配数值的 const 操作数整题排除；其余按程序常量处理。年份、计数、契约金额、固定投资基点等不应一概当连续舍入值，识别不清时排除。
- 同一绑定输入的重复引用使用同一变量。候选来源/精度不唯一时不任意挑选最粗值以增大现象。
- 精确有理数区间算术给外包络；用一致的内部输入角点给实际越界见证。只有包络越界、没有见证的标为 unresolved。中心值本来就不满足参考答案的，单列为中心不匹配，不归因于舍入。
- 分母同时列全部题目、数值题和可执行且绑定成功题。未解析题不当成稳定；以全部题目为分母报告已见证比例下界及未解决比例。

## 判分规则

1. 相对 1%：围绕 `qa.exe_ans` 的闭区间，零答案使用零宽区间，不悄悄添加绝对容差。
2. 显示精度：按 `qa.answer` 原始字符串的显示位数、百分比尺度建立舍入格。精度/尺度无法恢复者单列，不用 `str(float)` 编造位数。
3. 官方规则作补充：FinQA 程序结果在五位小数 round 后和 `qa.exe_ans` 比较。1% 与显示位数是本研究的审计规则，不写成官方规则。用精确十进制舍入格作敏感性分析时，说明其与 Python 二进制 float 的边界差别。

两套题目指定规则分别报告，主 gate 采用更宽松的 1% 规则，以避免只靠极窄答案显示格宣布继续。任一继续条件（全体 ≥5%，或运算组 ≥15%）优先于全体 <2% 的放弃条件；原题在小组和全体冲突时未指定优先级，故提前明确。组内同时给题数，不把样本量很小的小组当稳定一般规律。2%–5% 且无组达到15% 时交由 Theodore 判断。

## 运算、精度与附加分析

运算按程序结构确定：增长率优先（差值除以同一基数），其后比率、差值、求和、其他。输入有效位数按原始十进制表示计算并报告每题最少有效位数分组。

同量不同显示精度必须有实体、指标、时期和单位的证据；仅数值接近不算同一事实。自动筛候选后人工核验，报告候选覆盖及确认数，不把候选率冒充全体真实比例。报告不同出现位置的中心计算是否跨过判分边界，并讨论统一单位后的区间交集。

精度改善只作**合成反事实**：在同一物理单位下将输入半宽缩小 10、100、1000 倍。仅把百万改写成千、同步缩放数字及舍入误差并不会增加信息；没有更高精度原始披露时不声称真实数据已验证了该改善。

## 实现修正记录

首次 200 题解析试跑只用于检查来源解析；未改判定阈值。随后在随机 20 题的源阅读中发现常量词汇、整数股份和多层表头问题；将来源精度不唯一、来源身份不唯一及明显精确量排除。第一次全量来源核查（固定种子 20261116，从当时 199 个 test 越界题抽 25 个）又发现整数门店/呼叫中心数量和 `per common share` 股息措辞漏检，补上语义排除并全量重跑。test 越界数从 199 降为 196。重复精度核验发现“两个年份均为 2.6”会只出现一个文字span却指两个事实，故同一步两个相同原始数字参数整题排除，不能假定 x-x 恒为0。另修复leading-dot小数及文本预处理附加的重复括号百分数。以上是解析及类型修正，没有按结果更改 5%/15%/2% gate。排除规则偏保守且不构成完整语义解析器。
