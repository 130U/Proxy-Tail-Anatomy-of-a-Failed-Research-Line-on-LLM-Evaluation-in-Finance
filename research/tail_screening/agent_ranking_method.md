# 128 条 Codex agent 排序盲试：能测什么

2026-11-16。仅使用当前 Codex agent 的输出，不另接模型 API、不训练模型。本备忘支持一次有限样本可行性实验。

**这个设计能测量参考排序的头部被另一排序保留多少，以及结果对重排输入有多敏感；不能凭它验证渐近加宽定律。** 输出采用有序组，同组表示模型未能可靠区分。自报的“0.97”“8.6 分”等数字不是 token logprob，也不因此成为有校准意义的概率。

Qin 等的 *Large Language Models are Effective Text Rankers with Pairwise Ranking Prompting*（Findings of NAACL 2024）§3.1 对每个文档对交换输入顺序询问两次，两次偏好不一致时记为平局；§3.3 还明确承认两两比较未必传递。因此，pairwise 不是自动免疫顺序偏差的工具，也不能把矛盾比较当成严格全序。该文 §2.2 讨论 listwise 的顺序不一致与输出缺漏。本实验可借用“保留平局”的处理，但不沿用其最终分数并列时回退到初始排序的规则，否则输入位置会重新进入输出。[原文，§§2.2、3.1–3.3](https://aclanthology.org/2024.findings-naacl.97.pdf)。

Tang 等的 *Found in the Middle: Permutation Self-Consistency Improves Listwise Ranking in Large Language Models*（NAACL 2024）§2.2 在固定指令下随机打乱同一候选集，再聚合输出排序；§3.2 研究位置偏差。这直接支持“相同提示、换输入顺序重跑”的必要性。然而，其聚合理论和多次实验不能推出“本次两次排列已经去除了偏差”。两次运行足以发现明显不稳定；两次一致也不能证明所有排列都一致。这些文献研究的是排序任务，本次金融文本上的偏差幅度仍须实际测量。[原文，§§2.2–2.3、3.2](https://aclanthology.org/2024.naacl-long.129.pdf)。

建议把两个独立随机排列 \(\pi_1,\pi_2\) 先固定，两档模型都读取同一对排列，形成“模型 × 顺序”的四次运行；指令、样本内容和输出格式相同。每次使用独立的干净上下文，隐藏人工标签、其他运行输出及希望出现的结论，样本 ID 只作定位。这里的“独立”指运行隔离和排列的生成方式，**不意味着模型误差在统计上独立**。若解码随机性不能固定，两次输出差异同时包含顺序影响与运行波动，只能报告为重复运行敏感性，不能归因为纯位置效应。

先比较同一模型两次运行的头部重合，再解释模型之间的重合与加宽曲线。若同模型换序的变化已与跨模型差异相当，跨模型结果不足以归因于模型档位。不要从四次组合中挑选最支持预期的一条；保留主比较和全部重复运行的结果范围。这个范围是本次运行敏感性，不是四个独立数据集构成的置信区间。模型型号及配置需可辨认：若两个 agent 实际调用相同模型、相同配置，它们是同模型重复，不是廉价／昂贵两个模型；即使确为不同模型，在没有可比成本记录时也只能称两个模型配置。

对于无并列的排序，记参考模型前 \(k\) 条为 \(A_k\)，候选模型前 \(m\) 条为 \(B_m\)，定义

\[
\widehat R(k,m)=\frac{|A_k\cap B_m|}{k},\qquad
\widehat q_\gamma(k/128)=\frac{\min\{m:\widehat R(k,m)\ge\gamma\}}{128}.
\]

加宽倍数就是 \(m/k\)。这些量只依赖集合和顺序，故无需连续分数、概率校准或 logprob；严格单调变换也不会改变结果。负面一端按反向排序同样计算。它们是这 128 条样本、这个参考排序下的描述量，既不是对真实金融价值的召回，也不是样本外的召回保证。listwise 排名还可能依赖整个候选集，不能将它冒充为每条文本固有且不随候选集变化的连续评分。

有并列时，主结果可只在完整有序组的边界上计算，使用实际 \(k/128\)、\(m/128\)；这会使曲线更粗，却保留真实分辨率。若必须显示固定 \(k,m\)，应对参考端和候选端边界并列的所有允许取法报告 recall 的最小值与最大值，并据此给出加宽范围。不要按 ID 或输入位置强行打破并列后只报告一个数。如果 128 条被拆成互不比较的小批，各批局部名次也不能直接拼成全局 top-k。

128 条在 1% 尾部只有约 1–2 条，2% 只有约 2–3 条；即使取 \(k=8\)，recall 的最小步长仍是 12.5 个百分点，90% 目标事实上要求 8 条全部找回。应以明确的 \(k\) 和实际比例报告曲线，避免把整数取整包装成精确的“1% 尾部”。两个输入排列增加的是排序测量的重复，不会把样本量从 128 变成 256；四次运行也不会变成 512 条独立金融事件。

因此，本轮可交付的是带并列处理和换序敏感性的有限 \(p\) 曲线，以及“排序分辨率是否足够、模型间差异是否超过同模型波动”的判断。\(p\to0\) 的条件极值定律需要随样本增大仍有足够尾部观测，并控制阈值与估计误差；固定 128 条没有这种信息，拟合一条 log–log 直线也不能提供。这里不估计渐近 \(\alpha\)，也不把候选模型相对参考模型的差异称为真实模型质量差距。
