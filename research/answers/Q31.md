# Q31: Ordinal outputs, stochastic dominance and financial specifications

Date: 2026-11-15 · Internet access: verified first, then stopped · Status: partly complete.

## 1. Conclusion

Constraining conditional distributions by a partial order on the inputs is an existing statistical problem. Combining a cumulative logit with a monotone latent variable guarantees FOSD, but FOSD is not the same as preserving the predicted label, nor does it automatically correspond to the author's stance. A monotone specification for financial figures must restrict the context and the meaning of the indicator; one cannot go directly from "higher revenue" to "the author is more bullish".

## 3. Novelty judgment

- Judgment: FOSD and monotone statistical structures **have been done**; the specific combination for financial text has not been established.
- Confidence: high for the components; low for validity of the financial semantics.
- Keywords: `ordinal regression stochastic dominance cumulative link monotonic`.
- Correction to the advisor: UP is a distributional order constraint that can express an output specification for upward evidence, but it is not a complete formalization of LBL.

## 4. Minimal viable test

Independent derivation in this round: fix θ_1<⋯<θ_(K−1) and F_i(g)=σ(θ_i−η(g)). If η is non-decreasing, then every F_i is non-increasing, so the class distribution shifts upward in the FOSD sense. This constrains only tail probabilities and does not guarantee that each intermediate class probability is non-decreasing. The three-class distributions q=(0.6,0.3,0.1) and q'=(0.2,0.3,0.5) satisfy upward FOSD, but the argmax changes from the first class to the third; this is a counterexample showing that UP does not imply LBL.

The task should be restricted to "the direction of the current figure relative to a baseline given by the context", with baseline identification, period pairing and the good/bad direction of the indicator labelled separately. Revenue growth, liability growth and loss growth cannot share one monotone direction without a sign specification. If the input fully provides the figures to compare, the threshold rule must be run first; the text encoder has a testable role only when contextual interpretation is still needed.

If the modified figure g also changes c, the thresholds or the indicator to be compared, it is outside the intervention set of the theorem above. The admissible interventions should be recorded, the non-monotone coordinates held fixed, and counterfactual pairs used to check whether semantic labellers accept the result.

## 5. Veto conditions

If labellers consistently reject the required direction on the pre-specified intervention set, withdraw the stance monotonicity specification. If a text-free rule model is enough, do not treat the structural property as a necessary reason to train an LM.

## 6. Uncertainties

A full-text comparison of CORAL, CORN and all monotone ordinal models has not been completed; financial/psychological empirical work supporting monotonicity of author stance has not been searched. What holds at present is a conditional mathematical result, not a universal law of the behaviour of financial agents.
