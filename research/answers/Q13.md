## 1. Conclusion

Achieving unit equivariance with dimensionless features is an existing method. Classification probabilities are dimensionless outputs and can be invariant under a suitable representation; monetary outputs should be equivariant. The sufficiency argument in the advisor's draft holds, but it needs every channel to be normalized; "any dimensionless group loses no expressiveness" is too strong. Changes of physical representation must be distinguished from real economic interventions.

## 4. Minimal viable test

Define x'_j=x_j∏_l a_l^(D_lj) with the dimension matrix D and positive scales a. If Db=0 and the monomial is well defined, then π_b(x')=π_b(x). If the text normalization satisfies c(x')=c(x), the model q=H(π(x),c(x)) is exactly invariant. This sufficiency proof does not require training from scratch.

Expressiveness counterexample (derived in this round): with only one signed amount x, positive scale transformations preserve sign(x). But the only dimension-zero monomials of a single variable with non-zero dimension are constants, which cannot represent sign(x). One must therefore restrict to a positive non-zero domain and use a complete invariant that separates orbits, or keep information such as sign, zero values and missingness. Choosing two ratios does not automatically give the expressiveness of all unit-invariant functions. Using denominator + fixed epsilon breaks strict scale invariance; the denominator must be constrained away from zero, or a same-scale reference must be used.

A scale change in a report must change both the numbers and the unit text; thousands and millions should be normalized to the same fact. Doubling a company's revenue while holding other variables fixed is not a unit transformation and cannot be removed. Different currencies at exchange rates from different points in time are also not a single positive-scale group intervention.
