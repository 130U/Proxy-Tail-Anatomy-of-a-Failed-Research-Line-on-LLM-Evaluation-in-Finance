# Q29: From poisoning certification to temporal contamination certificates

Date: 2026-11-15 · Internet access: yes for the first half of the round, then stopped at the user's request · Status: partly complete.

## 1. Conclusion

DPA's voting certificate can be carried over to the counterfactual model obtained after deleting late-arriving documents, provided that the whole computation of the uncontaminated partitions stays unchanged. Both pointwise and collective robustness have precedents. In particular, the bagging collective certification of Chen et al. 2022 is more directly relevant than the GNN collective work the advisor listed. Statistic intervals themselves cannot automatically be listed as a first; the research difference should lie in the temporal sources, the connection between audit and budget, and real non-emptiness.

## 4. Minimal viable test

Fix the class order; the winner a has n_a votes, and at most k base classifiers change. A sufficient condition is n_a−n_b≥2k+1[b<a] for all b≠a. A winner with a smaller index can win in the worst-case tie; therefore "any prediction needs at least 2k+1 partitions" is not a necessary condition without exceptions. For k>0, with all votes for the smallest class and m=2k, that class can still be kept.

In the original DPA, one arbitrary sample replacement counts twice, as a deletion plus an insertion; in this project, a content modification with a fixed ID and a fixed partition can count as only one partition. This is a different threat model and must be written out explicitly. When only documents with wrong timestamps are deleted, no IDs move, but retraining a shared tokenizer, feature normalization or backbone on suspect data still affects every partition. A frozen backbone solves the problem only if that backbone is itself acceptable.

For each test sample, compute the set of reachable labels, then take the minimum/maximum of the bounded per-item score to give a conservative interval. A tighter method must constrain all test points to share the same set of affected partitions; an ILP can serve as the baseline. Small-scale exhaustive enumeration should cover ties, empty partitions, cross-partition modifications and multi-point shared budgets. Large-scale solving should report a verifiable bound and the solver gap, rather than passing off a non-converged optimum as a certificate.

## 5. Veto conditions

If existing temporal-contamination work covers the same assumptions and statistic bounds, withdraw the corresponding claim of originality. If the suspect window changes any shared training component, the current k-partition guarantee does not hold. If the k needed by the real audit exceeds the available vote margin, report the certificate as empty; do not tune parameters to hide the failure.

## 6. Uncertainties

Certified accuracy on text tasks, the accuracy cost of a frozen backbone, and 2023–2026 follow-up work have not been fully checked. Chen et al. report NP-hardness; this round did not independently verify their full complexity proof, and the BILP formulation by itself cannot serve as a proof of NP-hardness. All candidate mathematical differences in this note must be checked against the formal theory notes.
