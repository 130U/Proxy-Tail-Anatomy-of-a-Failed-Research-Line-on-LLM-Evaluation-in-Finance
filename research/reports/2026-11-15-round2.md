## 3. Core mathematical results and numeric evidence

The source for every number in this section is **our experiment: constructed vote matrices, exact rational arithmetic**.

Let B be the set of affected heads shared by all test points, and u_jc the number of votes that unaffected heads give to class c. With ties broken toward the smallest index, class c is reachable if and only if for every d≠c:

`u_jc + |B| >= u_jd + 1[d<c]`.

Enumerating only exactly min(k,m) allowed affected heads is enough to cover every "at most k" case, because a newly allowed head can keep its original vote. For fixed B, accuracy can be optimized point by point; macro-F1 must keep the links among per-class support counts, TP and prediction counts. Adding up per-class F1 extremes gives only an outer envelope; the joint-count DP is exact only within an explicit relaxed threat model.

| Constructed example | Independent per-point budget | Result with a shared head set |
|---|---|---|
| 4 points, 2 heads, 1 head allowed to change, both true labels of the two classes present | accuracy and macro-F1 both [0,1] | accuracy [1/4,3/4]; macro-F1 [1/5,11/15] |
| 3 points, 5 heads, 1 head allowed to change, all three true labels present | Optimizing each class's F1 separately can form a [4/9,2/3] outer envelope | Joint optimization gives macro-F1 constant at 5/9 |

The second example stresses that "safe but loose" and "exact" must be kept apart. The program does not claim that any real training process can reach these endpoints; consistency on identical inputs, realizability by the training function and similar conditions have been relaxed.

Audit example: N=20, n=16, x=0, α=1/20, exact K_u=1. The accuracy and macro-F1 intervals above are both derived from the event K_true≤1, so α does not need to be split in two. Here x=0 is a **manual input**; this round did not actually audit 16 documents.

## 4. What exact audit planning means

For a given tolerable budget B, after zero findings K_u≤B if and only if:

`C(N-(B+1), n) / C(N,n) <= alpha`.

This gives the minimum integer n and does not rely on the 3N/n approximation. For six sets of hand-made vote counts with assumed N=1000 and m=11, the zero-finding audit sizes needed to certify 1/3, 1/2, 2/3 and all points are 393, 527, 777 and 950 respectively. High coverage can be driven by a few points with zero vote margin, not only by the total number of shards.

These are not EDGAR-scale numbers, real model vote margins, or audit success probabilities. The audit must fix n in advance; if errors are found, one should invert again using the actual x, and must not keep adding samples until the interval looks good while still using the same fixed-time coverage rate.

## 5. Corrections to round 1 material

- The round 1 statement "real data is unavailable" was too broad. Further checking shows that the raw corpora exist locally; see the inventory report. What remains undone is applicability, the time semantics of sources, an independent test set, and a complete certificate on a real model. The old 24M per-item results cannot be recovered; that is a separate matter from whether new models can be trained.
- Having source files locally is not the same as having a historical information-set certificate. For a page crawled in 2026 that is labelled with a 2011 publication date, the content hash proves the consistency of the local snapshot; it does not automatically prove that this version was publicly available in 2011.
- WP0.2 allows synthetic experiments and negative results; one cannot say the prescribed four-configuration experiment was not done just because permission gave no gain. Its scientific interpretation is still limited by the confound between task saturation and the regularization strength of the shuffle.
- Theory and implementation both use fixed-K-class macro-F1, with a zero-denominator contribution of 0. Under full contamination, if only s classes have true support, the macro-F1 upper bound is s/K and should not always be written as 1.

The independent review found no substantive error in this round's envelopes within the listed assumptions, but it does not replace real training, real timestamp audits, analytic evaluation or an external literature check. There is currently no basis for declaring the project complete or the full goal blocked.
