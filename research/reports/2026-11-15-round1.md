## 1. One-paragraph summary

This round took the first step from the advisor's hypotheses to reviewable proofs, offline computation and an executable foundation. The P1 chain of audit, contamination, voting and a fixed statistic can hold under explicit assumptions, but statements such as "3N/n", "at least 2k+1 shards" and "authoritative timestamps are automatically leak-free" need qualification. The P2 results on monotonicity, FOSD, sensitivity and unit invariance can be formalized, but the basic components have prior work, and they do not require training the text encoder from scratch. The research evidence in the public repository is narrower than the design documents. The old predictions/weights are unavailable, so the 24M paired comparison cannot be reproduced. The newly built synthetic ablation has been run. The results show that the task is too easy, and the permission term did not beat the edit CE from the same batch. **The work currently cannot pass G0/G1, and it cannot be called a completed publishable innovation or a certificate on real financial data.** This package gives Fable a corrected research starting point, runnable code, and clear decisions for the next round.

## 3. Status of the advisor's hypotheses

| Hypothesis | Status | Correction and basis |
|---|---|---|
| Training from scratch is an irreplaceable precondition for both P1 and P2 | Revised | P1 needs all training dependencies to be auditable, which does not logically mean training must start from scratch. P2 only needs structural isolation and constraints, and can use an existing frozen text encoder. See Q03/Q10. |
| No-look-ahead has not yet been formalized | This broad statement is overturned | Temporal non-interference already exists; the works checked did not certify black-box model weights. See Q03. |
| Collective statistic certificates are new | Revised | DPA, Finite Aggregation and bagging collective certificates already exist. The candidate difference lies in the temporal source and audit chain, the cost and the width. See Q29. |
| With zero findings, k is about 3N/n | Holds conditionally | It is the scale of an upper confidence bound for fixed n, uniform sampling without replacement and an audit with no misjudgments. It is not a lower bound on the number of mislabels, and it is an approximation for small sampling fractions. See T1.4. |
| m≥2k+1 is a necessary condition for any prediction to be certifiable | Counterexample exists | With a fixed lowest-index tie-break winner, a unanimous vote with m=2k can also be robust. The strict vote-margin condition is still the usual safe condition. |
| Without a robust point prediction there can be no useful statistical interval | Does not hold | A score that is insensitive or only partly sensitive to labels can still have a narrow interval. "Non-empty" must be defined by a practical target such as width/coverage. |
| The authoritative EDGAR timestamp makes the core absolutely correct | Not verified | Content-version binding, the true availability time and the extraction pipeline are still needed. Real EDGAR has not been downloaded or audited yet. |
| None of the P2 dimensionless features lose expressive power | Revised | Needs a complete set of invariants and a domain of validity. The sign counterexample for signed amounts under positive scaling shows that sign/zero cannot be dropped. |
| T2.2 is monotone in all numeric coordinates | Revised | Only in the designated M coordinates, with the other coordinates and the context fixed. The derivative result generally holds only almost everywhere. |
| xVal can directly satisfy "c does not depend on g" | Does not hold | xVal injects the values into the backbone; a bypass should be designed. See the ledgers for Q10/Q12. |
| After calibration we know each prediction's error probability p_i | Does not hold | Calibration is not the same as the true per-point marginals. The conditional results of P3 also need a treatment of marginal uncertainty. |
| The pointwise average envelope applies to all backtest statistics | Does not hold | It applies to accuracy and bounded pointwise losses. Macro-F1, Sharpe and drawdown need separate derivations and cannot simply reuse T1.3. |
| 0.655 being higher than 0.609 proves the model is more effective | Not supported | Paired predictions, cluster structure and an independent test are all missing. Overlap of marginal CIs is not a test of the difference. |

## 4. Decision gate materials

### G0: failed

1. Real family-cluster confidence intervals for the current 24M model and three unified real baselines: **not done**. The user stated that the original predictions/checkpoint should be treated as nonexistent; later work proceeds as building from scratch.
2. Permission ablation: **local synthetic smoke test done**. A more discriminating task and validation on a real corpus are not done.
3. Synthetic world: **core mechanism implemented and tested**. Coverage of syntax, units and comparison baselines is limited, so performance on natural text cannot be inferred from it.
4. WP0.4: only offline sample development was allowed; real source statistics were **not run**.

Reconstructed historical summaries and perfect synthetic scores are not used to stand in for missing gates. The research order "foundation first, then the main line" was followed strictly. No Phase 1 shard-model training and no real financial model experiment was carried out.

### G1: no flagship chosen yet

| Dimension | P1 | P2 |
|---|---|---|
| Novelty | Components exist; the specific combination from temporal audit to a model statistic has not been exhaustively checked | Components exist; the difference in the financial-semantics/parsing linkage has not been exhaustively checked |
| Non-emptiness | Computable under assumed parameters; real corpus size, contamination and vote margin unknown | Holds under ideal parsing and structural isolation; real parsing quality and task value unknown |
| Feasibility | CPU integer audit is feasible; the scale of shard training has not been measured | CPU math-head checks are feasible; the cost of a real model has not been measured |
| Narrative fit | Fairly close to the proved interval | Consistent with the sensitivity bound, but the case that training from scratch is necessary is weak |

**Recommendation: keep P1 as the priority candidate for validation, and do not record it as the chosen flagship.** If Fable insists that "must train from scratch" is a hard filter, P2 cannot pass that filter on the strength of these three structural theorems alone. Nor can P2 be judged as passing automatically just because P1 currently lacks real evidence.

## 5. Unexpected findings and numbers

All numbers in this section are at the "our experiment" level. With zero findings and α=0.05:

| Assumed N | Audit n | Exact K_u | 3N/n approximation |
|---:|---:|---:|---:|
| 100,000 | 1,000 | 297 | 300 |
| 10,000 | 1,000 | 28 | 30 |
| 1,000 | 500 | 4 | 6 |

These are design parameters, not measured EDGAR sizes. Actual certifiability also depends on the observed vote margin, the trusted core and all shared components. The statistical interval covers only the counterfactual clean model on the fixed test set. It is not automatically an interval for future returns or for population performance.

The synthetic experiment with four configurations and three seeds took about 25.88 seconds. It trained on 480 families, tested on 120 families, and used a paired cluster bootstrap over 30 companies. Raw CE, edit CE and permission accuracy all saturated; the observed macro-F1 difference, permission − edit CE, is 0. Zero errors make the bootstrap degenerate to [0,0] or [1,1]. **This is not a proof of exactly zero risk.** The retrained permission weights for seed11 are bit-identical on this machine.

The independent code review also pointed out that when REL is shuffled onto sample pairs with the same label, that margin loss is constant and its gradient is zero. The shuffled configuration therefore also changes the effective composition of the regularization, and it cannot serve as an equal-strength, purely semantic mismatch control. This round does not claim on this basis that permission is effective. The statistic checker was fixed for the problem that ordinary floating-point averaging can round inward. It now uses exact rational endpoints and rounds its output outward, and a new regression test passes.
