## Decision rules and boundaries

- `complete`: every acceptance item explicitly scoped in that row has matching evidence; this does not propagate upward into completion of the whole work package, phase or paper.
- `partial`: there are reviewable outputs, but at least one prescribed step, output or piece of acceptance evidence is still missing.
- `missing`: there is no completed output matching the item; adjacent theory, variables with the same name, or examples cannot substitute.
- `blocked`: used only for a specific sub-item with a stated reason, for example that new source material cannot be added under the current offline boundary; it is not a whole-project status and does not mean the rest of the offline work should stop.

The user's latest request is to do the research locally, and confirms that it should not depend on the old predictions/checkpoints and should be built from scratch. This takes priority over the networked task arrangements in the advisor files. At present no new requests, downloads, external messages or publications are made, and contact details are no longer requested. Sub-items that need real sources can continue once the user provides lawful local material on their own initiative or changes the access boundary. Real source material does not have to be obtained over the network, but it cannot be replaced by hand-made fixtures or simulated data.

**New finding on local material:** An [offline inventory](local_data_inventory.md) has been completed: the old repository contains `data/raw/candidates/sentfin/SEntFiN.csv`, 120 FOMC texts with 120 hash-matched HTML snapshots, and 28,486 Wikipedia snapshots. The absence of old checkpoints/per-row predictions does not imply that the raw data is also missing; local source/licence metadata and file identities have been checked, but whether the historical content versions, time/event semantics and task use are sufficient for a new certificate still needs verification. "Real results not completed" in the table below does not mean "no real raw material on this machine".

The advisor's definition of G0 keeps its original meaning: family-clustered intervals and three baselines for the old 24M, the permission ablation results, and a synthetic world into which contamination can be planted exactly. The old per-row evidence is now unavailable, and the summary numbers cannot recover the joint family structure. New training can produce a new complete evaluation, but cannot retroactively recover the missing evidence for the old 24M; if in future a completely new evaluation replaces the literal requirements of the original G0, it must be recorded as an explicit revision of the research plan, not silently substituted in the status table.

Evidence levels: the local numbers and tests in the tables below are all **our experiment**, the historical model numbers are **public repository summaries**, and the mathematical status is **conditional pen-and-paper derivation**. A bootstrap interval is not a finite-sample certification, finite tests are not a proof over the whole domain, the mere existence of code is not a completed run, and novelty is not determined by code complexity.
