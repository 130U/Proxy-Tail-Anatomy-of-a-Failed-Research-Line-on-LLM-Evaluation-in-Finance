# Round 6: P2 certificate width is determined by the semantic candidates

Date 2026-11-16; local research/certifiable branch, base commit 8e4dd0b33c95ac2ac1a6015eba6f2dfafe5c1254. This round involved no external access, no reading of private text, and no model training; all numbers are explicitly hand-set mathematical constructions. G0/G1 have not passed, and the new components do not change that.

## 1. Conclusion

**Neither numerical accuracy nor local per-branch monotonicity is enough to guarantee P2's end-to-end conclusion.** Two numerically exact semantic branches can still make the first/last class probability range from about 0.0067 to 0.9526; a system in which every branch has derivative ≤1/4 can still jump down by about 0.9640 under an input change of 2e−6 because the selector switches. So what really has to be controlled is the full candidate semantics, the branch correspondence and the acceptance rule, not just constraints on the head.

At the same time, if the task label is simply sign(x−b), then once the full semantics is fixed, the sign rule already gives the oracle answer. There is as yet no need to hand this task to an ordered learned head. This is the veto baseline that any further P2 research must face.

A minimal per-coordinate box is not the same as the jointly reachable set; wrapping model outputs in intervals is not the same as certifying true class probabilities. If independent rectangles lose known dependencies such as x=b, they artificially enlarge the intervals; only after proving that every candidate is a genuinely admissible world can the candidate-relative lower bound be interpreted as information non-identifiability.

## 3. Actual checks and negative results

Under the pre-registered main width gate 0.10, of the 25 equally weighted hand-made candidate problems, 3 were proven to pass, 22 were proven too wide, and 0 were numerically undetermined; the 0.05/0.20 sensitivity columns pass 2/5 respectively. 3/25 cannot be written up as an acceptance rate on natural corpora, nor can it be used to claim that path 02's real-validity gate failed. The numeric-bound probe can return undetermined, which avoids mistaking a conservative computed upper bound for an impossibility lower bound.

The first full main construction took 0.694 seconds; 14 implementation tests pass, and the independent review adds 331 rational assertions plus 729 coordinate checks at 216 interior support points. Checks used CPU and the standard library, no GPU/training. Peak memory was not measured; strict numeric endpoints are all stored as fractions, and decimals are for display only. The latest unified reproduction record lists the full project tests and run times separately.

The strongest positive result is that keeping the branch structure avoids unnecessary conservatism: when η can only be −4 or +4, the middle-class probability can be narrowed to about 0.040733; if they are first merged into the continuous interval [−4,4], a non-existent interior peak is introduced and the upper bound grows to 0.462117. This is a conditional exact-computation increment, and it is not used to claim originality or validity on natural tasks.

## 4. Effect on the P2/P05 path assessment

Known monotonicity, unit invariance, interval arithmetic and minimax diameter are tools, not new methods this project has discovered. The narrow question that can still be explored is: which semantic candidates in natural text can be reliably kept or excluded; and, after keeping shared dependencies and branch structure, whether more samples can be covered than with a rule-based scheme under the same post-acceptance risk and width conditions.

Still missing: real tuple/branch gold labels, a same-task rule baseline and a trained language proposer, an independent risk audit, and an originality check. Actual model Greeks, WP2.1 parse error rate, WP2.2 constrained training, WP2.3 soft/hard comparison and WP2.4 real-model unit-rewriting experiments were all not completed this round. The path ranking did not change automatically.

## 5. Specific questions for Fable

Please decide whether to narrow P2's near-term scientific object to a "semantic candidate set – coverage risk – output width" certificate, while allowing symbolic computation to replace unnecessary learned heads. If an ordered-probability head is still to be the core, one must first specify which random target with an exogenous directional basis truly needs probability learning; the label must not be changed on the fly to a market outcome without directional basis just to preserve the architecture.

Second, how should the tightness of the candidate set be checked? Checking only that the true interpretation is covered is not enough; if many illegitimate branches cause width failure, one should be able to distinguish analytic conservatism from a genuine lack of information. The Fable question pack is still waiting to be passed on; this round did not receive or fabricate any external opinion.
