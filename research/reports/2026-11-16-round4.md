# Round 4: a from-scratch baseline on a real-source task, and closing the review loop

**There is now a real, traceable new baseline, but the flagship research and the complete certificate are still not done.** This round built 14,284 entity samples from the SEntFiN raw CSV already on this machine, trained four simple systems and completed a paired evaluation. For the detailed setup, numbers and limits see the [experiment analysis report](../experiments/real_baseline/report.md). For the rules fixed before running see [PROTOCOL](../real_baseline/PROTOCOL.md).

This round ran inside the user's local boundary. There was no download of weights or data, no contact with third parties, no message sent to Fable, no push and no public release. The original repository and its uncommitted changes were not overwritten by this round's training. All row-level data, vocabularies, predictions and weights stay in research/private, and the handoff package excludes them.

## Key results and the judgments they change

Word TF-IDF/LR reaches a test macro-F1 of 0.79202 and the character model 0.75478. The pre-registered char−word difference is −0.03723, with a nominal 95% paired lexical-cluster bootstrap interval of [−0.05306,−0.02156]. Entity-only reaches 0.53359. This suggests that the entity field itself is worth controlling for, but it is not a causal explanatory share.

These are source sentiment labels for the designated entities, not stances on securities. The test set has 2,107 rows and 1,570 lexical clusters. There was no event gold standard and no out-of-time extrapolation. The new scores cannot be compared directly with the old 0.6549 to say which is better. The most useful research implication is that any later complex model must face simple references that have actually been run. It cannot claim necessity merely because a model was trained.

The 9 real LR fits and the predictions of the four systems took 13.81 seconds, all without convergence warnings. Preparation took 0.77 seconds and the bootstrap 2.31 seconds. The thread count reported by the library was 2 both before and after training. Peak memory was not measured. The development set selected C values of 10/1/0.1 respectively. Hyperparameters and grouping were not changed after looking at the test set.

## Decision gates

WP0.1 gains new baseline evidence on a real-source task. The old 24M cluster evidence is still unrecoverable, and the FinBERT and small-LLM baselines originally specified by the advisor are missing, so the original G0 remains failed. P1 still has gaps in the historical byte versions, the shared core and the complete PIT components. P2 still has gaps in the semantic tuples, a non-redundant task and a certificate from real training. The five-path report is still topic analysis and cannot be promoted to confirmed originality.

The next step can independently advance the complete PIT contract and counterexample checks for invariance under future appends, or narrow the assumptions/lower bounds of the audit-structure question. None of this requires breaking the offline boundary, and none of it can be replaced by this round's sentiment scores. The first questions for Fable are still: whether to accept the explicitly revised G0 and the "necessity of training from scratch" filter, and which falsifiable mathematical increment is worth making the flagship. The handoff materials are for the user to pass on; there is currently no direct communication channel to Fable.
