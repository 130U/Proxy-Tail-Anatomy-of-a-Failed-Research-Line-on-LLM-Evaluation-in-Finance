## 结果去向和追踪

- 第0–1批定位 Gittings、XBRL 及财报舍入背景；第2–3批检查 QA、ACL、arXiv 和基准社区关键词。FinQA/TAT-QA/ConvFinQA 加输入精度/条件数的查询没有给出可证明完成候选1的正文；这只是当前检索结果。
- 第4–8批追查会计关系、财务比率、interval arithmetic 和 rounded data。XBRL 规范是明确正面命中；中文“报表自动调整”只取得摘要/转载片段，不能提升为精确恢复先例。
- 第9–10批检索统计披露重构工作，取得 Dandekar2010 全文；沿其数值优化主题阅读 Salazar-González2005 期刊正文。
- 第9–11批查 Higham 原理出处，读到作者2021原文；2002教材仅核实书目信息，没有声称读完书。
- 第12–13批发现 VeriFin，继而直接读 v3 §3.6 数学定义以区分输入点值和输出容差。
- 原生 GitHub GH1（Arelle）和 GH2（EnvCommons）的指定查询返回空；GH2 的全库查询返回10项，其中多数与本判定无关，不作相关论文数。另一个 QA grader 线索为 [whileai-sdk #255](https://github.com/LMikeH/whileai-sdk/issues/255)，自报 SEC XBRL task 的 grader 假阴性改进，但不是 FinQA 输入舍入分析。
- 根代理另独立读 EnvCommons PR #2/#3/#4，结论纳入总报告，不能用本分工的 issues 空结果覆盖直接 PR 证据。
- Yan2026（arXiv2611.02461）由候选3分工交叉送达，直接读取全文的§§1–6、AppendixD/E；FinanceReasoning 的附录定位由候选4/5分工交叉送达，本分工复读相关 HTML。这些**不虚构为额外关键词检索**。
- 引用链主要沿 XFinBench、FinanceReasoning、RAG-CoT 的相关工作和参考文献，进入 FinQA/TAT-QA/ConvFinQA 后续评测、XBRL规范和统计披露方法。没有获取三项基准全部被引论文的机器导出，也没有把此局部追查称为完整引用图遍历。
