# T3 一页结论：按预定门继续，但先核查模型误设

2026-11-16｜**正式判定：继续；唯一通过的是 λ 门。研究建议：仅做一次模型设定核查，暂不扩大评分或主张新机制。** 固定 gpt-6-sol / low，30 条自造单事实各八次，390 对双顺序各四次：**88 次主调用、3,360 分全部完成**。

**最明确的观察是：组合分更接近相加，简单平均表现很差。** 误差单位均为0–100量表上的分数；留出仍使用被留事实的单条标定分。

| 候选规则 | 拟合 RMSE | 按原子留出 RMSE |
|---|---:|---:|
| 截断相加 | 5.235 | 5.235 |
| 简单加权平均 | 12.144 | 12.144 |
| 负面加权平均 | 10.300 | 10.564 |
| 带中性初始意见的对照族（预设诊断） | 4.966 | 5.027 |

最后一项仅比相加略好，不能凭这一差距确认内部平均机制；同向组合的局部误差仍较大。

| 正面先说减负面先说 | −0.168［−1.643，1.160］分 | 顺序门未通过 |

十条中性标题的单条均分均为50。只看坏消息＋中性，收缩为1.176［−0.153，2.359］分；没有形成清晰的“添一句中性话便能冲淡坏消息”证据。正正、负负组合分别有73.3%、64.4%比两条中较强的一条更极端，平均超出2.844、1.167分；不能据此排除带初始意见的平均模型。

**λ 为什么不能直接叫“坏消息影响是好消息的2.69倍”？** 在归一化平均模型中，正面＋中性约被预测成 dP/2，λ无法修正；负面＋中性却能用较大λ将 λ/(1+λ)·dN 拉回单条。因此，接近相加的行为也可能促使这个受限模型估出λ>1。λ模型的最大改善恰在负面＋中性组，而其整体留出误差仍约为相加的两倍。这是尚未排除的模型误设解释，不是已证实的负面主导机制。**保留预定“继续”判定，但不把参数显著等同于研究贡献。**

查重未确认同一核心测量的完整重复；正负信息倒序评分已有[直接先例](https://aclanthology.org/2025.nlp4dh-1.18.pdf)，金融中性稀释也已有[人工聚合公式先例](https://www.ecb.europa.eu/pub/pdf/scpwps/ecb.wp3283~df0633dfd3.de.pdf?495f4d0ec675f3cbda625976eb20dff3=)。可能的增量只能是特定评分协议的可复现实测，不能称首次发现平均或顺序偏差。[文献门及边界](literature_gate.md)

区间来自1000次原子分层及整轮评分重采样，属于30条手工事实的敏感性范围，不保证推广到金融新闻总体。首版P/N/Z编号可能暗示极性，4次/120分已保留并排除；主实验改为随机盲编号，修订在主代理读取首版分数值前决定。实际总计92次调用；主实验无失败或重试。[执行与复算说明](execution_notes.md)

**给Fable的下一步：** 先用现有数据检验允许正负系数自由变化的相加模型，判断λ信号是否随函数设定消失；明确标为事后探索，不能替换本次冻结判定。通过这一步后才值得考虑新事实、第二模型或理论扩展。
