## Fixed behavior

- Completed downloads, the task exclusion pool, the vocabulary and the shards are reused read-only after their manifest, provenance, configuration and hashes are verified. Artifacts generated by older versions remain compatible.
- If something is incomplete, damaged, or was built with different parameters, the old files are kept and the message clearly says to restore a complete backup or to choose a new version. Nothing is deleted or overwritten automatically.
- A new runtime can restore the raw data, shards and vocabulary from `MyDrive/130U-FinLLM/seeds/seed_v1/`. Edits to the human-review CSV are not overwritten by a re-export.
- Before the backup, 01a re-verifies all training inputs, so that interrupted outputs are not taken as completed results.
- 01a can run on CPU; only 02a requires a GPU. The user's log for this run shows `torch=2.11.0+cpu` and `cuda_available=false`, so it cannot serve as a T4 run record.
